Whatfix enables you to create Beacons using Whatfix Studio. Expand the following accordions for more details:

Step 1: Create the Beacon

Use the following steps to create a Beacon collection:

{{snippet.Studio_create_Beacon}}

Info:

  • A Beacon collection is a group of Beacons that usually appear on the same page.

  • The Beacon collection name is only for your reference and is not visible to users.

  • Every Beacon must belong to a collection, even when a page has only one Beacon.

  1. Click Add Beacon.

  2. Select an element on the application where the Beacon must appear.

Info:

To switch to navigation mode while selecting an element, press Shift+M.

  1. On the tooltip that appears on the application, enter a description for the Beacon.

Info:

  • Users see the Beacon description when they hover their cursor over the Beacon.

  • Use the formatting toolbar on the tooltip to change the font size and text color, or to add links, images, and videos.

  1. In Studio, click the Beacon name, and then enter a name for the Beacon.

Info:

  • By default, Whatfix names Beacons in sequence, such as Beacon 1 and Beacon 2.

  • The Beacon name is only for your reference and is not visible to users.

  1. On the Configurations tab, expand Interaction, and then under Disappear Beacon, select when the Beacon stops displaying.

  2. To open a Flow, Link, Video, Image, or PDF when users click the Beacon, select the content type from the Beacon action dropdown. For more information, see Attach a flow, video, or link to a Beacon.

  3. Expand Appearance, and then under Tooltip, click Change to select a tooltip template.

  4. Click the Color swatch, and then select a color or enter a hex code.

  5. Under Icon, select the Type, Color, and Size of the icon.

Info:

  • By default, Whatfix provides four types of icons for a Beacon: Custom, Radial, Ripple, and Speckle.

  • Select the Custom icon to enter the text of your Beacon in the Custom beacon text box.

  • You can't change the size of the Custom icon.

  • To add your own icons for Beacons, see Use custom icons for Beacons.

  • Once you start selecting the element to place the Beacon, your cursor changes to the set Beacon style.

  1. Expand Positioning, and then adjust the position of the Beacon.

Info:

Positioning has two modes:

  • In Basic mode, select one of the 8 positions around the selected element.

  • In Advanced mode, click the arrows to move the Beacon by the number of pixels set in the Movement on key click(px) dropdown.

  • Click the Lock icon to unlock and reposition the Beacon.

  1. Expand Tooltip Position, and then select the position of the tooltip.

  2. To fix the Beacon to the page or to an element, or to censor sensitive information, expand Additional Options. For more information, see Anchor content to a Page and Anchor content to an Element.

Info:

  • To set Visibility Rules for this Beacon only, use the Visibility Rules tab. For more information, see New Visibility Rules for Beacons in Studio.

  • To customize the Beacon styling with CSS or AI, use the CSS tab. For more information, see Use CSS for tooltip customization.

  1. Click Save Beacon.

Info:

To add more Beacons, in the Beacon Collection panel, click Add Beacon, and then repeat steps 5 to 16.

  1. In the Beacon Collection panel, click Save.

Note:

  • When you save the Beacon collection, Whatfix automatically adds it to the Content tab on the Whatfix Dashboard.

  • To display the Beacons on your application, move the Beacon collection to the Production stage on the Content tab.

  • Content moves from Draft to Ready, and then to Production.

Info:

To edit a Beacon in a collection while you create it, see Edit Beacons.

Step 2: Configure the Visibility Rules for the Beacon Collection

Configure the Visibility Rules for a Beacon collection in Studio or on the Whatfix Dashboard.

In Studio

Use the following steps to configure the Visibility Rules in Studio:

  1. In the Beacon Collection panel, click the Collection Visibility tab.

  2. Configure where, when, and to whom the Beacon collection appears.

  3. Click Save.

On the Whatfix Dashboard

Use the following steps to configure the Visibility Rules on the Whatfix Dashboard:

{{snippet.click_content_beacon}}

  1. Hover your cursor over the Beacon collection you want to configure, and then click Edit.

  2. Click Collection Visibility.

  3. Expand Where does the Beacon collection appear?, and then configure the URL and Page Tags. For more information, see Set Where your Content or Widget appears with the New Visibility Rules.

  4. Expand When does the Beacon collection start and stop appearing?, and then configure when the Beacon collection starts and stops appearing. For more information, see Set When your Content appears.

  5. Expand Who does the Beacon collection appear to?, and then configure who sees the Beacon collection. For more information, see Set Who can see your Content or Widget with the New Visibility Rules.

  6. Click Save.
