# PRD: Unified Content Experience

## Summary
Today, authors configure in-app content through two separate tabs in the
Whatfix Studio dashboard: the **Content tab** (Articles, Links, Images,
Videos, PDFs) and the **Widgets tab** (Smart Tips, Beacons, Flows,
Launchers, Blockers, Pop-ups, Self Help, Task List, Surveys). This split
is confusing for new authors and doesn't reflect how these content types
actually relate to each other.

## What's changing
We are merging authoring entry points for the following content types
into the Content tab: **Smart Tips, Beacons, Flows, Launchers, Blockers,
Links, Images, Videos, PDFs, and Articles**. Authors will create and
manage all of these from a single Content tab going forward.

**Pop-ups, Self Help, Task List, and Surveys are explicitly out of scope
for this change** and will continue to be configured from the Widgets
tab exactly as they are today. We are not touching these.

## Rollout
This ships to DAP for Web only, effective 2026-10-20. Other product
lines (DAP for Desktop, DAP for Mobile, DAP on OS) are not affected by
this change and keep their existing tab structure.

## Before / after
- Before: "Go to the Widgets tab to create a Smart Tip, Beacon, Flow,
  Launcher, or Blocker."
- After: "Go to the Content tab to create a Smart Tip, Beacon, Flow,
  Launcher, or Blocker."
